# Desafio de criação de Dashboard de Vendas no Power BI 

O desafio consiste em criar 3 relatórios baseados nos dados em um Banco de Dados exemplo do aplicativo Power BI Desktop. Onde na qual: 

1º Dashboard: É um Relatório de Vendas Considerando Produtos e Segmento
2º Dashboard: É um Relatório de Vendas Considerando Países e Lucro
3º Dashboard: É um Distribuição de Lucro, Vendas e Unidades vendidas por país e segmento
